# Reference fixtures

Inputs and expected outputs shared by the R package (`tests/testthat/fixtures/`)
and the Python package (`tests/fixtures/`). `inst/scripts/make_fixtures.R`
describes each file and the function settings used.

The expected outputs (`*_blocks.csv`, `*_density.csv`) were generated by
`inst/scripts/make_fixtures.R` with the R implementation.
`inst/scripts/make_fixtures.m` computes the same outputs with the original MATLAB
implementation (R2026b): the block indices and their order are identical, the
cross-omics densities are identical, and the within-omics densities differ by
less than 3e-8 relative to their values.

Block indices are 1-based. Densities are compared with a relative tolerance of
1e-6, because the MATLAB implementation computes the peeling in single
precision.
