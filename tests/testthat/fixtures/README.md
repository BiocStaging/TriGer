# Reference fixtures

Inputs and expected outputs shared by the R package (`tests/testthat/fixtures/`)
and the Python package (`tests/fixtures/`). `inst/scripts/make_fixtures.R`
describes each file and the function settings used.

The expected outputs (`*_blocks.csv`, `*_density.csv`) in this version were
generated by `inst/scripts/make_fixtures.R` with the R implementation.
Running `inst/scripts/make_fixtures.m` regenerates them with the original MATLAB
implementation; the tests then compare both packages with MATLAB.

Block indices are 1-based. Densities are compared with a relative tolerance of
1e-6, because the MATLAB implementation computes the peeling in single
precision.
